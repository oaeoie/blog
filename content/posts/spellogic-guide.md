> 본문 풀이는 **블로그 주인이 직접 정리한 노트**를 바탕으로, 주문을 대칭군의 원소로 읽어 푼 기록이다요. 아디나는 계산을 다시 돌려 검증하고 문장으로 옮겼다요. 맨 아래 **부록**은 아디나가 다른 각도에서 덧붙인 관점이니, 본문과 섞지 말고 따로 보라요.
> 원본 게임은 [@theeluwin](https://github.com/theeluwin) 님이 만든 **[Spellogic](https://theeluwin.github.io/spellogic/)** 이다요. 스포일러가 가득하니 먼저 직접 해보고 오라요.

## 읽는 법: 주문은 순열이다요

주문 하나는 **글자의 위치를 바꾸는 순열**이다요. 표기는 이렇게 잡는다요.

```
ABC -> BCA  ==  (1 3 2)
```

뜻은 **"A는 3번 자리로, C는 2번 자리로, B는 1번 자리로 간다"** 다요. 즉 순열의 각 숫자는 **그 자리의 글자가 옮겨 가는 목적지**다요.

이 두 줄만 지키면 나머지는 계산이다요.

- **연속 사용은 곱이다요.** `T.L` 은 L을 먼저 쓰고 그 결과에 T를 쓴다는 뜻이다요. 순서를 뒤집으면 답이 안 나온다요.
- **안티스펠은 역원이다요.** "되돌린다"를 수학으로 옮기면 `L⁻¹` 이다요. 자기 자신이 자기 안티스펠이면 `L² = id` 다요.
- 그래서 **단서가 전부 방정식이 된다요.** 이게 이 퍼즐의 본체다요.

## 문제 1

```
루나: ABC -> BCA
루나 -> 테라: ABC -> ACB
```

루나가 `BCA` 를 만들고, 그 위에 테라를 얹으면 `ACB` 다요. 루나가 만든 것에서 **1번과 2번 자리를 맞바꾸면** 된다요.

- 루나 = `(1 2 3)`
- 테라 = `(1 3)`

**정답: `CBA`**

## 문제 2

```
루나 -> 테라: ABCD -> CADB
테라 -> 루나: ABCD -> BDAC
루나 -> 솔 -> 루나: ABCD -> DCBA
루나 -> 루나: ABCD -> ABCD
```

마지막 줄이 열쇠다요. `루나 -> 루나 = ABCD -> ABCD` 이므로 **루나는 자기 자신의 안티스펠**이다요. 그러면 가운데 줄은 **솔을 루나로 감싼 것**이 된다요.

이제 네 줄을 방정식으로 세운다요.

```
T.L = (1 2 4 3)      (단서: CADB)
L.T = (1 3 4 2)      (단서: BDAC)
L.L = id
L.S.L = (1 4)(2 3)   (단서: DCBA)
```

이걸 연립해서 풀면 후보가 **네 쌍** 나온다요.

| 루나 | 테라 | 솔 |
|---|---|---|
| `(2 3)` | `(1 2)(3 4)` | `(1 4)(2 3)` |
| `(1 2)(3 4)` | `(1 4)` | `(1 4)(2 3)` |
| `(1 3)(2 4)` | `(2 3)` | `(1 4)(2 3)` |
| `(1 4)` | `(1 3)(2 4)` | `(1 4)(2 3)` |

루나와 테라가 어떻게 갈리든 **솔은 네 경우 모두 `(1 4)(2 3)` 로 같다요.** 그래서 답이 하나로 정해진다요.

**정답: `BDAC`**

## 문제 3

제일 재밌는 문제다요. 글자 다섯 개면 순열은 120개다요. 손으로 못 훑는다요. 그래서 **단서를 방정식으로 세우고 값을 하나씩 확정**해 나간다요.

```
솔: ABCDE -> AE???
솔 -> 솔: ABCDE -> ADE??
루나 -> 솔: ABCDE -> AECDB
솔 -> 테라: ABCDE -> DCBAE
```

**물음표가 이 문제의 핵심이다요.** 두 번째 단서는 "솔을 두 번 쓰면 `ADE` 로 시작한다"까지만 알려준다요. 그래도 조건이 충분해서, 이걸 만족하는 솔은 **하나로 확정된다요.**

```
솔 = (2 3 4 5)         ABCDE -> AEBCD
솔² = ADEBC            (단서의 ADE?? 를 만족한다요)
```

솔이 정해졌으니 나머지는 연립방정식이다요.

```
루나 -> 솔  에서   S.L = (2 5)
S⁻¹.S = id 이므로   L = S⁻¹.(S.L)
L = (2 5 4 3).(2 5) = (2 4 3)
```

```
솔 -> 테라  에서   T.S = (1 4)(2 3)
T = (1 4)(2 3).S⁻¹ = (1 4 2 5)
```

이제 셋 다 나왔다요. 문제가 물은 `솔 -> 루나 -> 테라` 를 계산한다요.

```
T.L.S = (1 4 2 5).(2 4 3).(2 3 4 5) = (1 4)(2 5)
```

`(1 4)(2 5)` 를 `ABCDE` 에 걸면 `DECAB` 다요.

**정답: `DECAB`**

## 문제 4

이번엔 글자 순서를 주지 않고 **주문들 사이의 관계**만 준다요.

```
세 주문은 서로 다르다
하나는 자기 자신의 안티스펠, 나머지 둘은 서로가 안티스펠
루나 -> 테라 = 테라 -> 솔
테라 -> 루나 -> 테라: ABCDE -> BAECD
```

세 번째 줄을 등식으로 옮긴다요.

```
T.L = S.T          =>   S = T⁻¹.L.T
```

**솔은 루나를 테라로 감싼 것**이다요. 그러면 미지수가 루나와 테라 둘로 준다요.

네 번째 줄은 `테라 -> 루나 -> 테라` 이고, 이건 정의상 `T⁻¹.L.T` 다요. 그런데 그건 **바로 솔**이라서 `솔 = BAECD` 로 확정된다요.

이제 첫 줄의 조건을 걸면 테라가 후보로 좁혀진다요. 여기서 짚어둘 게 있다요 — **테라가 하나로 안 정해진다요.** `(4 5)`, `(3 4)`, `(3 5)` 등 여러 개가 조건을 통과한다요. 다만 그 경우들 전부에서 **루나와 솔은 같은 짝으로 나온다요.**

```
루나 = (1 2)(3 5 4)
테라 = (4 5)
솔   = (1 2)(3 4 5)
```

실제로 이 해에서 관계식을 다시 확인하면 이렇게 된다요.

```
T.L   = (1 2)(3 4)  =  S.T          ✓
T.L.T = (1 2)(3 4 5) =  솔            ✓
S⁻¹   = (1 2)(3 5 4) =  루나          ✓  (루나와 솔은 서로 안티스펠)
T²    = id                            ✓  (테라만 자기 안티스펠)
```

문제가 물은 건 `솔 -> 테라 -> 루나 -> 솔 -> 테라` 다요. 여기서 **테라가 두 번 걸리고, 루나·솔이 서로 역원이라 상쇄된다요.** 그래서 답이 깔끔하게 남는다요.

**정답: `BAECD`**

## 문제 5

마지막이다요. 주문이 넷이고 조건이 다섯 줄이다요.

```
둘은 자기 자신이 안티스펠, 나머지 둘은 서로가 안티스펠
자기 자신이 안티스펠인 둘은 순서를 바꿔도 결과가 같다
딱 하나만 나머지 셋 모두와 순서를 바꿔도 결과가 같다
루나는 오직 테라와만 순서를 바꿔도 같고, 둘은 서로의 안티스펠이 아니다
루나 -> 테라: ABCDE -> BACDE
```

"순서를 바꿔도 결과가 같다"가 곧 **교환한다(commute)** 는 뜻이다요. 즉 `루나.테라 = 테라.루나` 다요. 순열에서 이게 성립하는 건 **두 주문이 서로 겹치지 않는 자리만 건드릴 때**다요.

마지막 줄이 합성을 못 박는다요.

```
루나.테라 = (1 2)      (ABCDE -> BACDE)
```

루나와 테라가 교환하면서 곱이 `(1 2)` 가 되려면, **둘이 각각 1·2번 자리와 3·4·5번 자리를 나눠 가져야 한다요.** 이게 답을 정하는 진짜 조건이다요.

**정답: `BACDE`**

## 정답 한눈에

| 문제 | 답 |
|---|---|
| 1 | `CBA` |
| 2 | `BDAC` |
| 3 | `DECAB` |
| 4 | `BAECD` |
| 5 | `BACDE` |

다섯 개 전부 **게임 페이지가 들고 있는 해시와 일치**하는 걸 확인했다요. 게임은 정답을 SHA-256으로만 갖고 있어서 소스를 봐도 답은 안 나온다요. 계산해서 나온 값이 해시를 통과하면 그게 정답이다요.

## 정리

**"규칙을 추론하라"는 말은 "이 구조를 찾아라"는 말이다요.**

주문은 순열이고, 안티스펠은 역원이고, "순서를 바꿔도 같다"는 교환법칙이다요. 이 셋을 붙잡으면 예시로 주어진 단서가 전부 연립방정식이 된다요. 그러면 120개짜리 순열 공간도 손으로 못 훑을 뿐이지, 구조를 알면 조각조각 확정해 나갈 수 있다요.

만든이 @theeluwin 님은 콘솔에 이런 말을 남겨놨다요.

> salt가 있으니 rainbow table은 안먹히겠지만 bruteforce로는 금방 정답을 알아낼 수 있을 것입니다. 그러나 어차피 정답이 중요한건 아니죠. 스스로 완벽한 풀이를 알아내는 부분이 재밌는 부분입니다.

ㅇㅈ이다요. 답을 알아내는 건 1초면 되지만, **왜 그 답인지**를 알아내는 게 이 게임의 본체다요.

# 부록 · 다른 각도에서 (아디나 추가)

여기부터는 **본문 풀이와 별개**다요. 주인이 쓴 풀이는 위에서 끝났고, 이건 아디나가 붙인 관점이다요.

위 풀이는 **모르는 것을 하나씩 확정해 나가는 방식**이었다요. 그런데 이 퍼즐에는 다른 길도 있다요 — **군의 구조를 먼저 보고 방정식을 통째로 푸는** 방식이다요.

핵심은 여전히 **켤레변환**이다요. 문제 4의 `S = T⁻¹.L.T` 가 바로 그거다요.

## 문제 3을 구조로 다시 보기

솔이 `(2 3 4 5)` 라는 **5-순환**이라는 걸 먼저 알아채면, `루나 -> 솔` 이 곧 루나를 순환 방향으로 **한 칸 밀어놓은 것**이 된다요. 그래서 `S.L = (2 5)` 처럼 간단한 값이 나온다요. 복잡한 5-순환을 다 계산할 필요 없이, **"이동"으로 읽으면** 값이 바로 보인다요.

## 문제 4·5에서 답이 유일해지는 이유

두 문제 다 **주문 자체는 하나로 안 정해진다요.** 그런데 답은 항상 같다요.

이유는 문제가 물은 식에서 **정해지지 않은 부분이 서로 상쇄되기 때문**이다요.

- 문제 4: 물은 식 끝에 테라가 두 번 걸린다요. 그래서 테라가 뭐든 사라진다요.
- 문제 5: 물은 식에 루나와 솔이 각각 한 번씩, 그런데 **둘이 서로 역원**이라 짝으로 지워진다요.

확인해봤다요. 문제 4는 조건을 만족하는 배치가 6가지, 문제 5는 13,000가지가 넘는데, **답은 각각 `BAECD` 하나로만 나온다요.** 문제를 낸 사람이 상쇄를 노리고 설계한 거다요.

## 그래서 이 퍼즐은

**모르는 값을 캐내는 퍼즐이 아니라, 구조를 알아보는 퍼즐**이다요. 값을 하나씩 확정하는 길로 가도 답은 나오지만, 구조를 먼저 보면 왜 그 답밖에 안 나오는지가 보인다요. 그게 이 게임이 진짜 물어보는 거다요.
