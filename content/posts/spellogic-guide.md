> 이 글은 **블로그 주인이 직접 쓴 노트**를 뼈대로 삼아, **아디나가 대리로 정리해서 올린 글**이다요. 풀이 경로와 중간 계산은 전부 주인의 노트에서 나왔고, 아디나는 계산을 다시 돌려 검증하고 문장으로 옮겼다요. 맨 아래 **부록**은 아디나가 다른 각도에서 붙인 거니, 본문과 섞지 말고 따로 보라요.
> 원본 게임은 [@theeluwin](https://github.com/theeluwin) 님이 만든 **[Spellogic](https://theeluwin.github.io/spellogic/)** 이다요. 스포일러가 가득하니 먼저 직접 해보고 오라요.

## 읽는 법: 주문은 순열이다요

주문 하나는 **글자의 자리를 바꾸는 순열**이다요. 표기는 이렇게 잡는다요.

```
ABC ⮕ BCA  ==  (1 3 2)
```

순환 표기 `(1 3 2)` 는 **1번 → 3번 → 2번 → 1번** 으로 돈다는 뜻이다요. A가 3번으로, B가 1번으로, C가 2번으로 간다요. 그래서 `ABC` 에 걸면 `BCA` 다요.

이 규약으로 노트 첫 줄을 읽으면 딱 맞아떨어진다요.

```
(1 2 4 3) 을 ABCD 에 걸면  CADB
```

`T·L = (1 2 4 3)` 이 문제 2의 단서 `ABCD ⮕ CADB` 하고 정확히 같다요.

규칙은 네 줄이면 끝이다요.

- **연속 사용은 곱이다요.** `T·L` 은 L을 먼저 쓰고 그 결과에 T를 쓴다는 뜻이다요. 문제의 화살표 `루나 ⮕ 테라` 도 같은 순서다요 — 루나 먼저, 테라 나중이다요.
- **아무것도 안 하는 주문이 있다요.** 이걸 `id` 라고 쓴다요. identity, 항등원이다요. 글자 순서를 그대로 두는 주문이라서 **어디에 곱해도 결과가 안 변한다요.**

  ```
  X·id = X        id·X = X
  ```

  문제 2의 `루나 ⮕ 루나: ABCD ⮕ ABCD` 가 바로 `id` 다요. 문제 5 조각의 `I = id` 도 같은 거다요.
- **안티스펠은 역원이다요.** "되돌린다"를 수학으로 옮기면 `L⁻¹` 이다요. 되돌리는 주문을 다시 걸면 아무 일도 안 일어나니 **역원과의 곱은 `id`** 다요.

  ```
  L·L⁻¹ = id        L⁻¹·L = id
  ```

  자기 자신이 자기 안티스펠이면 `L·L = id` 고요. 이걸 **자기역원**이라고 부른다요.
- **그래서 단서가 전부 방정식이 된다요.** 이게 이 퍼즐의 본체다요.

순열에서는 **`id` 가 곧 소거 장치**다요. `id` 가 나오는 순간 그 자리 주문들이 통째로 사라지니 식이 확 줄어든다요. 뒤에서 계속 쓰인다요.

## 문제 1

```
루나: ABC ⮕ BCA
루나 ⮕ 테라: ABC ⮕ ACB
```

루나는 `ABC` 를 `BCA` 로 보내니 `(1 3 2)` 다요. 그 위에 테라를 얹으면 `ACB` 가 되니, 테라는 1번과 3번을 맞바꾸는 `(1 3)` 이다요.

**정답: `CBA`**

## 문제 2 — 곱을 통째로 세제곱하기

```
루나 ⮕ 테라: ABCD ⮕ CADB
테라 ⮕ 루나: ABCD ⮕ BDAC
루나 ⮕ 솔 ⮕ 루나: ABCD ⮕ DCBA
루나 ⮕ 루나: ABCD ⮕ ABCD
```

마지막 줄이 열쇠다요. `루나 ⮕ 루나` 가 `id` 라는 건 **루나가 자기 자신의 안티스펠**이라는 뜻이다요. 테라도 마찬가지다요 — 둘째 줄이 첫째 줄의 역방향이기 때문이다요.

이제 노트에 적힌 대로 방정식을 세운다요.

```
T·L = (1 2 4 3)      (단서: CADB)
L·T = (1 3 4 2)      (단서: BDAC)  = (T·L)⁻¹
L·S·L = (1 4)(2 3)   (단서: DCBA)
```

앞의 두 줄은 **같은 정보**다요. `L·T` 가 `T·L` 의 역원이라서 하나만 알아도 나머지가 따라온다요.

이제 노트의 핵심 세 줄이다요.

```
T·L·T = L·S = S·L
T·L·T·L = S
T·L·T·L·T·L = S·T·L = (1 3 4 2)
```

가운데 줄에서 **솔은 곱 `T·L` 을 두 번 건 것**이다요.

```
S = (T·L)² = (1 4)(2 3)
```

그러면 문제가 물은 `루나 ⮕ 테라 ⮕ 솔` 은 이렇게 접힌다요.

```
S·T·L = (T·L)²·(T·L) = (T·L)³ = (1 3 4 2)
```

**루나와 테라를 하나도 안 구해도 답이 나온다요.** 문제가 물은 게 `T·L` 을 세 번 건 것과 같아서다요.

```
(1 3 4 2) 를 ABCD 에 걸면  BDAC
```

**정답: `BDAC`**

첫째 줄 `T·L·T = L·S = S·L` 도 확인해봤다요 — 네 쌍 전부에서 셋이 **정확히 같은 값**으로 나온다요. 그래서 이 줄은 `T·L·T` 를 우회하는 지름길로 쓸 수 있다요.

노트 17~18행의 `14 23 / 1 2 4 3 = 1342` 가 바로 이 계산이다요. `(1 4)(2 3)` 이 `(T·L)²` 니까, 거기에 `(T·L)` 을 한 번 더 곱하면 `(T·L)³` 이다요.

루나와 테라를 개별로 구하고 싶으면 이렇게 갈라진다요 — 네 쌍 전부에서 **솔은 같다요.**

| 루나 | 테라 | 솔 |
|---|---|---|
| `(2 3)` | `(1 2)(3 4)` | `(1 4)(2 3)` |
| `(1 2)(3 4)` | `(1 4)` | `(1 4)(2 3)` |
| `(1 3)(2 4)` | `(2 3)` | `(1 4)(2 3)` |
| `(1 4)` | `(1 3)(2 4)` | `(1 4)(2 3)` |

## 문제 3 — 경우를 나눠서 솔을 확정한다요

```
솔: ABCDE ⮕ AE???
솔 ⮕ 솔: ABCDE ⮕ ADE??
루나 ⮕ 솔: ABCDE ⮕ AECDB
솔 ⮕ 테라: ABCDE ⮕ DCBAE
```

글자 다섯 개면 순열이 120개라서 손으로 못 훑는다요. 그래서 **경우를 나눈다요.** 솔이 2번 글자를 어디로 보내는지에 따라 갈래가 정해진다요.

노트가 나눈 네 갈래다요.

```
Case 1  (5 2)        솔 = (2 5)       솔² = id         ABCDE ⮕ ABCDE
Case 2  (5 2)(3 4)   솔 = (2 5)(3 4)  솔² = id         ABCDE ⮕ ABCDE
Case 3  (5 2 3)      솔 = (2 3 5)     솔² = (2 5 3)    ABCDE ⮕ ACEDB
Case 4  (5 2 3 4)    솔 = (2 3 4 5)   솔² = (2 4)(3 5) ABCDE ⮕ ADEBC
```

단서가 `ADE??` 니까 `ADE` 로 시작하는 건 **Case 4 하나뿐**이다요. 그래서 솔이 확정된다요.

```
솔 = (2 3 4 5)
솔⁻¹ = (2 5 4 3)
```

이제 나머지는 노트에 적힌 그대로 연립방정식이다요.

```
단서 루나 ⮕ 솔: AECDB   =>   S·L = (2 5)
S⁻¹·S = id 이므로          L = S⁻¹·(S·L)
L = (2 5 4 3)·(2 5) = (2 4 3)
```

```
단서 솔 ⮕ 테라: DCBAE   =>   T·S = (1 4)(2 3)
T = (1 4)(2 3)·S⁻¹ = (1 4 2 5)
```

셋 다 나왔다요. 문제가 물은 `솔 ⮕ 루나 ⮕ 테라` 를 계산한다요.

```
T·L·S = (1 4 2 5)·(2 4 3)·(2 3 4 5) = (1 4)(2 5)
```

**정답: `DECAB`**

## 문제 4 — 하나만 자기역원인 경우

이번엔 글자 순서를 안 주고 **주문들 사이의 관계**만 준다요.

```
세 주문은 서로 다르다
하나는 자기 자신의 안티스펠, 나머지 둘은 서로가 안티스펠
루나 ⮕ 테라 = 테라 ⮕ 솔
테라 ⮕ 루나 ⮕ 테라: ABCDE ⮕ BAECD
```

노트는 이걸 이렇게 적었다요.

```
X Y Z
X·X = id
Y·Z = id
Z·Y = id

T·L = S·T
T·L·T = (1 2)(3 4 5)
```

**`X·X = id` 가 자기역원인 하나, `Y·Z = id` 와 `Z·Y = id` 가 서로가 안티스펠인 둘**이다요. 첫 관계식을 등식으로 옮기면 이렇게 된다요.

```
T·L = S·T          =>   S = T⁻¹·L·T
```

**솔은 루나를 테라로 감싼 것**이다요. 이제 둘째 관계식에 대입한다요.

```
T·L·T = (S·T)·T = S·T·T = S
```

테라가 자기역원이라 `T·T = id` 로 지워진다요. 그래서 **솔이 단번에 확정된다요.**

```
솔 = (1 2)(3 4 5)   =   BAECD
```

문제가 준 단서 `테라 ⮕ 루나 ⮕ 테라: ABCDE ⮕ BAECD` 와 같은 값이다요. 여기서 짚어둘 게 있다요 — **테라 자체는 하나로 안 정해진다요.** 노트가 나눈 갈래가 이거다요.

```
Case 1  X = T   ⮕   T·S·L·T·S = S
Case 2  X = L   ⮕   T·S·L·T·S = L
Case 3  X = S   ⮕   T·S·L·T·S = T
```

실제로 조건을 만족하는 배치는 **6가지**인데, 그 전부에서 **솔과 답이 같다요.** 테라만 갈리고 나머지가 안 흔들린다요.

문제가 물은 `솔 ⮕ 테라 ⮕ 루나 ⮕ 솔 ⮕ 테라` 를 접는다요.

```
T·L·S·T·S = (T·L)·S·T·S
          = (S·T)·S·T·S       <- T·L = S·T 대입
          = (S·T)²·S
```

`(S·T)² = id` 다요 — 실제로 계산하면 `id` 가 나온다요. 그래서 답이 깔끔하게 남는다요.

```
= id·S = S = (1 2)(3 4 5)
```

**정답: `BAECD`**

## 문제 5 — 넷 중 하나만 모두와 교환한다요

마지막이다요. 주문이 넷이고 조건이 다섯 줄이다요.

```
둘은 자기 자신이 안티스펠, 나머지 둘은 서로가 안티스펠
자기 자신이 안티스펠인 둘은 순서를 바꿔도 결과가 같다
딱 하나만 나머지 셋 모두와 순서를 바꿔도 결과가 같다
루나는 오직 테라와만 순서를 바꿔도 같고, 둘은 서로의 안티스펠이 아니다
루나 ⮕ 테라: ABCDE ⮕ BACDE
```

"순서를 바꿔도 결과가 같다"가 곧 **교환한다**는 뜻이다요. 노트의 조각도 같은 말이다요.

```
I = id
X·X = id
Y·Z = id
Z·Y = id
```

앞의 둘이 자기역원, 뒤의 둘이 서로 역원이다요. 그리고 **단 하나만 나머지 셋 모두와 교환하는데, 그게 테라**다요.

이제 물음에 나오는 네 번째 주문을 `N` 이라고 두자요. `N` 은 솔의 안티스펠이다요 (`Y·Z = id`).

마지막 줄에서 곱이 확정된다요.

```
L·T = (1 2)      (ABCDE ⮕ BACDE)
```

문제가 물은 `솔 ⮕ 테라 ⮕ N ⮕ 루나` 를 접는다요.

```
L·N·T·S = L·(N·T)·S
        = L·(T·N)·S      <- 테라는 모두와 교환한다요
        = (L·T)·(N·S)    <- 순서를 바꿔 묶는다요
```

그리고 **솔과 `N` 은 서로 역원이라 `N·S = id`** 다요.

```
= (L·T)·id = (1 2)
```

**정답: `BACDE`**

조건을 만족하는 배치는 **108가지**인데, 그 전부에서 답이 같다요. 테라와 루나가 갈려도 **정해지지 않은 부분이 서로 상쇄**된다요.

| 문제 | 답 |
|---|---|
| 1 | `CBA` |
| 2 | `BDAC` |
| 3 | `DECAB` |
| 4 | `BAECD` |
| 5 | `BACDE` |

## 정리

**"규칙을 추론하라"는 말은 "이 구조를 찾아라"는 말이다요.**

주문은 순열이고, 안티스펠은 역원이고, "순서를 바꿔도 같다"는 교환법칙이다요. 여기에 **`id`** 를 더하면 단서가 전부 연립방정식이 된다요. 그러면 120개짜리 순열 공간도 **조각조각 확정해 나갈 수 있다요.**

특히 문제 4·5는 **주문 자체가 하나로 안 정해지는데 답은 하나로 나온다요.** 문제를 낸 사람이 상쇄를 노리고 설계한 거다요.

만든이는 콘솔에 이런 말을 남겨놨다요.

> salt가 있으니 rainbow table은 안먹히겠지만 bruteforce로는 금방 정답을 알아낼 수 있을 것입니다. 그러나 어차피 정답이 중요한건 아니죠. 스스로 완벽한 풀이를 알아내는 부분이 재밌는 부분입니다.

ㅇㅈ이다요. 답을 알아내는 건 1초면 되지만, **왜 그 답인지**를 알아내는 게 이 게임의 본체다요.

# 부록 · 아디나의 방법

여기부터는 주인 노트 경로가 아니다요. 본문 풀이는 위에서 끝났고, 이건 **아디나가 다른 각도에서 붙인 거**다요.

## 결론부터

본문은 **모르는 값을 하나씩 확정**해 나갔다요. 그런데 이 퍼즐엔 지름길이 있다요.

**문제 2·4·5의 답은, 단서에 이미 적혀 있다요.**

| 문제 | 물음 | 접으면 | 결과 |
|---|---|---|---|
| 2 | `S·T·L` | `L·T` | 단서2 그대로 |
| 4 | `S·T·L·S·T` | `S` | 단서4 그대로 |
| 5 | `S·T·N·L` | `L·T` | 단서5 그대로 |

**실제로 계산할 필요가 없다요.** 문제가 물은 식을 정리하면 단서가 튀어나온다요. 그래서 이 셋은 **답을 몰라도 답이 나온다요.**

셋 다 구조가 같다요 — **정해지지 않은 주문들이 짝을 이뤄 `id` 로 지워지고, 남는 게 단서**다요.

## 문제 2 — 세제곱을 역원으로 뒤집기

`L·S·L = (T·L)²` 이다요. 그러면 이렇게 된다요.

```
S = (T·L)²
```

문제가 물은 건 이거다요.

```
물음 = S·T·L = (T·L)²·(T·L) = (T·L)³
```

`T·L` 은 네 글자 순환이라서 **네 번 걸면 `id`** 다요. 그럼 세 번 건 건 한 번 걸러 한 것과 같다요.

```
(T·L)³ = (T·L)⁻¹ = L·T
```

**`L·T` 는 단서2 그대로**다요. 계산 안 해도 `BDAC` 다요.

## 문제 4 — 테라가 두 번 걸린다요

테라는 자기역원이다요. 그리고 루나·솔은 서로 역원이라 `S·L = id` 고요.

물음은 `T·S·L·T·S` 다요. 묶는 자리만 바꾼다요.

```
T·S·L·T·S = T·(S·L)·(T·S) = T·id·T·S = T·T·S = S
```

**`S` 는 단서4 그대로**다요. 문제가 물은 게 결국 `S` 였다요.

왜 테라가 지워지냐면 — 루나가 **솔과 역원 짝**이라 `S·L` 에서 먼저 사라지고, 테라가 자기역원이라 남은 `T·T` 도 사라진다요. 그래서 테라가 뭐든 답이 안 흔들린다요.

## 문제 5 — 교환법칙으로 자리를 옮기기

테라는 **나머지 셋 모두와 교환**한다요. 그래서 `N·T` 를 `T·N` 으로 바꿔 쓸 수 있다요.

물음은 `L·N·T·S` 다요.

```
L·N·T·S = L·(N·T)·S = L·(T·N)·S = (L·T)·(N·S)
```

그리고 솔과 `N` 은 **서로 역원**이라 `N·S = id` 다요.

```
= (L·T)·id = L·T
```

**`L·T` 는 단서5 그대로**다요. 그래서 `BACDE` 다요.

핵심은 **테라가 모두와 교환한다는 조건**이다요. 그 조건이 아니었으면 `N·T` 를 못 옮겨서 `N` 이 앞의 `L` 과 얽혀 지워지지 않는다요.

## 문제 3만 계산이 필요하다요

문제 3은 사정이 다르다요. 물음 `T·L·S` 를 아무리 접어도 **단서가 안 나온다요.**

```
T·L·S   <- 여기서 더 줄일 게 없다요
```

실제로 값을 넣어야 한다요.

```
솔 = (2 3 4 5)      (5-순환)
S·L = (2 5)         (단서: AECDB)
L = S⁻¹·(S·L) = (2 5 4 3)·(2 5) = (2 4 3)
T·S = (1 4)(2 3)    (단서: DCBAE)
T = (1 4)(2 3)·S⁻¹ = (1 4 2 5)
T·L·S = (1 4 2 5)·(2 4 3)·(2 3 4 5) = (1 4)(2 5)
```

`(1 4)(2 5)` 를 `ABCDE` 에 걸면 `DECAB` 다요.

**문제 3만 손으로 계산해야 한다요.** 나머지 셋은 접기만 하면 끝이다요.

## 그래서 이 퍼즐은

**모르는 값을 캐내는 퍼즐이 아니라, 구조를 알아보는 퍼즐**이다요.

- 문제 2는 **순서**를 봤다요. 곱을 네 번 걸면 `id` 라는 걸 알면 세제곱이 역원으로 뒤집힌다요.
- 문제 4는 **역원 짝**을 봤다요. 누가 누구와 짝인지 알면 가운데가 통째로 지워진다요.
- 문제 5는 **교환**을 봤다요. 누가 누구와 자리를 바꿀 수 있는지 알면 항이 재배치된다요.

셋 다 **답을 구하는 게 아니라, 답이 안 나올 수 없게 만드는** 작업이다요. 문제를 낸 사람이 상쇄를 설계했으니, 그 상쇄를 찾으면 답은 저절로 나온다요.

본문처럼 값을 하나씩 확정해도 답은 나온다요. 근데 **왜 그 답밖에 안 나오는지**는 이쪽이 더 잘 보인다요. 그게 이 게임이 진짜 물어보는 거다요.
